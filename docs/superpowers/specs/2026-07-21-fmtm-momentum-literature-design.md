# FMTM 文章论文观点整合设计

## 目标

在现有 FMTM 文章框架中加入 Fang、Griffin 以及 Baltas 与 Kosowski
三篇研究，使它们共同支撑一个有限而明确的判断：动量不是单一策略，
不同信号、资产、市场状态和时间尺度可能形成不同的动量暴露，因此将
长周期动量与较短周期动量并置具有分散化上的合理性。

## 结构

在“FMTM 是一个很好的样本”之后新增“动量不止一种”一节：

1. 用简短定义区分截面动量、时间序列动量和期货趋势跟随。
2. 依次提炼三篇论文的核心贡献：
   - Fang 等：个股时间序列动量具有条件性，在信息传播较差的股票和
     市场状态中更明显。
   - Griffin 等：价格动量与盈利动量包含不同信息，跨国家、跨信号的
     动量配置具有分散化价值。
   - Baltas 与 Kosowski：CTA 趋势跟随可由多频率时间序列动量解释，
     快、中、慢信号并非完全相同的暴露。
3. 将三篇论文收束为“动量收益取决于信号、资产、市场状态、时间尺度
   与执行方式”的文章主张。

在“它应该放在哪里？”一节加入组合层面的回扣：持有长周期动量的同时
配置较短周期动量，并不是重复持仓的同义词；两者可能捕捉不同速度的
价格延续，但这种分散化并不保证在所有市场状态下成立。

## 论证边界

- 不把三篇论文写成对 FMTM 产品表现的直接验证。
- 不声称已知 FMTM 专有模型的具体参数、因子权重或潜在变量。
- 明确 FMTM 历史很短，无法仅凭已实现收益辨认其长期策略暴露。
- 使用“可能”“提供了合理性”等审慎措辞，不把历史样本结论写成未来
  收益保证。
- 保留现有个人随笔语气，避免扩写成完整文献综述。
